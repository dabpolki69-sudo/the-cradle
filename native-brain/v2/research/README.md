# Sylvex Pilot Research Tests

Status: exploratory draft; not validated and not yet run against Sylvex Brain.

This file contains ten original synthetic cases: six memory-focused and four gap-honesty-focused. They are a small pilot to refine evaluation questions, not a statistically meaningful benchmark and not a claim about current system capability.

## Use boundaries
- Keep this research artifact separate from runtime code and deployment.
- Record actual outputs and scoring rationale when tests are run; do not infer results in advance.
- Review each expected behaviour critically; tests can encode bad assumptions too.
- If later adapting external dataset records, record source, revision, original record ID, licence, and any restrictions.
- Treat dataset content as untrusted input; do not execute code from datasets or import sensitive personal data.
- Memory and gap-honesty results should be scored separately where possible.

The CSV currently uses original synthetic cases only; no external dataset records have been copied.
